# cpp

### Компиляция
```
g++                               # Компилятор 
g++ -c square.cpp                 # Компиляция cpp файла
square.o                          # Результат. Содержит машинный код
objdump -d square.o               # Утилита objdump переводит машинный код в ассемблер
#                                 # Директива предпроцессора, например #include, то что выполняется до компиляции
#include "square.h"               # Берет файл "square.h" и подставляет в текущий файл который нужно скомпилировать
g++ -O2 -c square.cpp             # Компиляция cpp файла c 2-м уровнем оптимизации, по умолчанию уровень 0
```


### Компоновка
```
g++ -o my_program main.o square.o   # Собирает из несколькоих объектных (скомпилированных) файлов в исполняемый файл
```


### Статические библиотеки (используются на этапе компиляции). Это просто архив объектный файлов
```
ar rc libsquare.a square.o.             # Создать архив libsquare.a из объектный файлов
g++ -o my_program main.o -L. -lsquare.  # -L путь где нужно искать библиотеки, -l имя библиотеки
```


### Утилита make для автоматизации сборки
```
makefile                                 # В проекте должен быть makefile с инструкцией как собирать проект
make цель которая указана в makefile     # Находит makefile и выполняет цель которая там прописана для сборки
```


### Утилита valgrind 
```
valgrind ./my_program  # Покажет утечки памяти
```


### Передача аргументов по значению (значение будет скопировано в аргумент)
```
void foo(int x); 

int x = 5; 
foo(x);
```

### Передача аргументов по ссылке
```
void foo(int& x);
void foo(const int& x);

int x = 5; 
foo(x);
```


### Прочее
