# cpp

### Компиляция
```
g++                               # Компилятор 
g++ -c square.cpp                 # Компиляция cpp файла
square.o                          # Результат. Содержит машинный код
objdump -d square.o               # Утилита objdump переводит машинный код в ассемблер
#                                 # Директива предпроцессора, например #include, то что выполняется до компиляции
#include "square.h"               # Берет файл "square.h" и подставляет в текущий файл который нужно скомпилировать
g++ -O2 -c square.cpp             # Компиляция cpp файла c 2-м уровнем оптимизации, по умолчанию уровень 0
```

### Компоновка
```
g++ -o my_program main.o square.o   # Собирает из несколькоих объектных (скомпилированных) файлов в исполняемый файл
```
