## Компиляция

**Компилятор:** `g++`

Компиляция `.cpp`-файла в объектный файл:

```bash
g++ -c square.cpp
```

Результат:

```text
square.o
```

`*.o` — объектный файл, содержащий машинный код.

Посмотреть машинный код в виде ассемблера:

```bash
objdump -d square.o
```

### Директивы препроцессора

Директивы, начинающиеся с `#`, обрабатываются **до компиляции**.

Например:

```cpp
#include "square.h"
```

Подключает содержимое `square.h` к текущему файлу.

### Оптимизация

Компиляция с оптимизацией второго уровня:

```bash
g++ -O2 -c square.cpp
```

По умолчанию используется уровень оптимизации `O0`.

## Компоновка

Компоновка (линковка) нескольких объектных файлов в исполняемый файл:

```bash
g++ -o my_program main.o square.o
```

Здесь:

* `main.o` — объектный файл;
* `square.o` — объектный файл;
* `-o my_program` — имя результирующего исполняемого файла.

## Статические библиотеки

Статические библиотеки используются на этапе компоновки.

По сути, статическая библиотека — это архив объектных файлов.

### Создание библиотеки

Создать библиотеку `libsquare.a` из `square.o`:

```bash
ar rc libsquare.a square.o
```

### Подключение библиотеки

```bash
g++ -o my_program main.o -L. -lsquare
```

Параметры:

* `-L.` — искать библиотеки в текущем каталоге;
* `-lsquare` — подключить библиотеку `libsquare.a`.

> Префикс `lib` и расширение `.a` при использовании `-l` указывать не нужно.

## Make

`make` — утилита для автоматизации сборки проекта.

В проекте должен находиться файл:

```text
Makefile
```

В `Makefile` описываются правила сборки проекта.

Запуск цели:

```bash
make <цель>
```

Например:

```bash
make all
```

`make` находит `Makefile` и выполняет указанную цель.

## Передача аргументов

### Передача по значению

При передаче по значению аргумент копируется:

```cpp
void foo(int x);

int x = 5;
foo(x);
```

Внутри `foo` создаётся отдельная переменная `x`.

---

### Передача по ссылке

```cpp
void foo(int& x);
void foo(const int& x);

int x = 5;
foo(x);
```

`int&` позволяет изменять исходную переменную.

`const int&` не позволяет изменять исходную переменную через ссылку.

---

### Передача по указателю

```cpp
void foo(int* x);
void foo(const int* x);
```

Пример:

```cpp
int x = 5;
foo(&x);
```

> В исходной заметке было `int* x = 5`, но указателю нельзя напрямую присвоить значение `5`. Для передачи адреса переменной используется `&x`.

## Callback-функции

Callback — функция, которую передают в другую функцию для последующего вызова.

Указатель на функцию:

```cpp
using fooptr = void(*)(int);
```

Здесь `fooptr` — тип указателя на функцию вида:

```cpp
void foo(int);
```

Передача функции:

```cpp
fooptr ptr = foo;
```

Функция, принимающая callback:

```cpp
void prc(fooptr foo);
```

Пример:

```cpp
void foo(int i)
{
    // ...
}

using fooptr = void(*)(int);

void prc(fooptr callback)
{
    callback(10);
}

int main()
{
    prc(foo);
}
```

## Лямбда-функции

Общий синтаксис:

```cpp
[список захвата](список параметров) {
    // тело функции
}
```

С указанием возвращаемого типа:

```cpp
[список захвата](список параметров) -> возвращаемый тип {
    // тело функции
}
```

Пример:

```cpp
auto foo = [](int x) {
    return x < 3;
};
```

### Захват переменных

Захват всех переменных по значению:

```cpp
auto foo = [=]() {
    // ...
};
```

Захват всех переменных по ссылке:

```cpp
auto foo = [&]() {
    // ...
};
```
