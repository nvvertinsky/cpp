## Компиляция
```
g++                                   # Компилятор
g++ -c square.cpp                     # Компиляция .cpp-файла в объектный файл square.o, содержащий машинный код
objdump -d square.o                   # Посмотреть машинный код в виде ассемблера
g++ -O2 -c square.cpp                 # Компиляция с оптимизацией второго уровня, по-умолчанию 0
g++ -o my_program main.o square.o.    # Компоновка (линковка) нескольких объектных файлов в исполняемый файл
MinGW                                 # Набор инструментов для разработки C++ под Windows, содержит g++, cdb.exe, mingw32-make
ar rc libsquare.a square.o            # Создать библиотеку libsquare.a из square.o
g++ -o my_program main.o -L. -lsquare # Подключение библиотеки
make <цель>                           # Утилита для автоматизации сборки проекта. В проекте должен быть файл Makefile
valgrind ./my_program                 # valgrind используется, в частности, для поиска утечек памяти и других проблем с памятью.
```

## Передача аргументов

### Передача по значению

При передаче по значению аргумент копируется:

```cpp
void foo(int x);

int x = 5;
foo(x);
```

Внутри `foo` создаётся отдельная переменная `x`.

---

### Передача по ссылке

```cpp
void foo(int& x);
void foo(const int& x);

int x = 5;
foo(x);
```

`int&` позволяет изменять исходную переменную.

`const int&` не позволяет изменять исходную переменную через ссылку.

---

### Передача по указателю

```cpp
void foo(int* x);
void foo(const int* x);
```

Пример:

```cpp
int x = 5;
foo(&x);
```

> В исходной заметке было `int* x = 5`, но указателю нельзя напрямую присвоить значение `5`. Для передачи адреса переменной используется `&x`.

## Callback-функции

Callback — функция, которую передают в другую функцию для последующего вызова.

Указатель на функцию:

```cpp
using fooptr = void(*)(int);
```

Здесь `fooptr` — тип указателя на функцию вида:

```cpp
void foo(int);
```

Передача функции:

```cpp
fooptr ptr = foo;
```

Функция, принимающая callback:

```cpp
void prc(fooptr foo);
```

Пример:

```cpp
void foo(int i)
{
    // ...
}

using fooptr = void(*)(int);

void prc(fooptr callback)
{
    callback(10);
}

int main()
{
    prc(foo);
}
```

## Лямбда-функции

Общий синтаксис:

```cpp
[список захвата](список параметров) {
    // тело функции
}
```

С указанием возвращаемого типа:

```cpp
[список захвата](список параметров) -> возвращаемый тип {
    // тело функции
}
```

Пример:

```cpp
auto foo = [](int x) {
    return x < 3;
};
```

### Захват переменных

Захват всех переменных по значению:

```cpp
auto foo = [=]() {
    // ...
};
```

Захват всех переменных по ссылке:

```cpp
auto foo = [&]() {
    // ...
};
```
